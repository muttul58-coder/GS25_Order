  • 1 주문서 상품코드를 알 때. 바로 입력하는 게 제일 빠릅니다. 열기
  • 2 상품 찾기 화면 코드를 모를 때. 왼쪽에서 찾아 담으면 오른쪽 주문서에 들어갑니다. 열기

인쇄물은 두 화면 어디서 뽑아도 똑같습니다. 상품 찾기 패널은 인쇄되지 않습니다.

새 시즌으로 바꾸기 설날·추석마다 이 순서대로

  • 1 바코드 PDF 올리기 새 시즌 바코드북 PDF를 끌어다 놓고 Commit changes. 열기
  • 2 시즌설정.txt 고치기 시즌 이름 · 카탈로그 주소 · 바코드 PDF 이름 · 행사 날짜 3가지. 열기
  • 3 갱신 실행 Run workflow ▾ 클릭. 새 PDF를 올렸으면 '바코드도 다시 만들기' 체크. 열기
  • 4 매뉴얼 보기 위 3단계의 자세한 설명과, 실행이 빨간 ✗ 로 끝났을 때의 대처. 열기

클로드 코드에 맡기는 경우

위 1~3단계를 대신 시킬 수 있습니다. 건네줄 것은 두 가지뿐입니다.

  1. 새 시즌 카탈로그 사이트 주소 예: https://gs25mobile.com/2027_1st/category — 주소창에 보이는 그대로면 됩니다
  2. 바코드북 PDF 파일을 주시거나, 내려받을 수 있는 링크를 주시면 됩니다

이렇게 말씀하시면 됩니다.

새 시즌 갱신해줘
카탈로그: https://gs25mobile.com/2027_1st/category
바코드 PDF: (파일 또는 링크)

그러면 이렇게 진행됩니다.

  • 카탈로그가 열리는지, 상품 수, PDF와 상품코드가 1:1인지 먼저 확인
  • 사전행사 배너 그림을 읽어 행사 날짜 3가지를 뽑아냅니다 — 맞는지 사장님께 먼저 여쭙습니다
  • 처음 보는 구매혜택 아이콘이 있으면 그림과 함께 보여드리고 확인받습니다 (2+1과 3+1은 글자 하나 차이라 단정하지 않습니다)
  • 시즌설정.txt를 고쳐 올려둡니다 → 실행 버튼은 사장님이 누르시는 쪽을 권합니다

★ 바코드 스캔 확인만은 대신 못 합니다. 카탈로그에 바코드 번호가 아예 없어서 맞춰볼 정답이 없습니다. 인쇄해서 스캐너로 찍어보는 것은 끝까지 사장님 몫입니다.

갱신 뒤 확인할 것 (생략 금지)
  • 실행 기록의 사전행사 품목 수가 카탈로그 배너의 "총 ○○품목" 과 같은지
  • 주문서에서 상품코드 5개쯤 넣어 가격이 카탈로그와 같은지 (상품 이름은 갱신할 때 PDF와 카탈로그를 자동으로 대조하고, 하나라도 다르면 갱신이 멈춥니다)
  • 행사가 카탈로그와 같은지 (본행사 상품은 행사 미리보기로 확인)
  • ★ 인쇄해서 실제 스캐너로 바코드를 찍어보기 — 명절마다 같은 코드가 다른 상품을 가리키므로, 화면만 봐서는 절대 알 수 없습니다
  • 화면이 예전 그대로면 Ctrl+F5 로 강제 새로고침
