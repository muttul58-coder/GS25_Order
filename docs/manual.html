즐겨찾기는 이것 하나 — 관리자 홈

👉 관리자 홈 열기 즐겨찾기 0

아래 주소들이 전부 이 안에 버튼으로 들어 있습니다. 그것보다 중요한 건, 열자마자 지금 어떤 상태인지를 먼저 보여준다는 점입니다.

  • 지금 올라가 있는 시즌 이름과 상품 개수
  • 오늘이 행사 시작 전 / 사전행사 / 본행사 중 어디인지, 다음 날짜까지 며칠 남았는지
  • 마지막으로 갱신한 날짜
  • 그래서 지금 무엇을 하면 되는지 한 문단
왜 만들었나 1년에 두 번만 하는 일이라 “지금 이게 정상인가?” 부터 헷갈리게 됩니다. 그 답을 매뉴얼에서 찾지 않고 화면에서 바로 보시라고 만든 화면입니다. 값은 전부 현재 데이터에서 읽어오므로 시즌이 바뀌어도 저절로 맞습니다.
공유 주의 이 주소는 비밀번호가 없습니다. 주소를 아는 사람은 누구나 열 수 있으니 관리자만 즐겨찾기 하시고, 점원·손님에게는 주문서 주소만 알려주세요. (관리자 홈의 주문서 칸에 주소 복사 버튼이 있습니다.)

화면 3가지 주문서는 코드를 아는 상태에서 바로 치는 화면입니다. 상품 찾기 화면(6번)은 왼쪽에서 이름·분류로 찾아 담는 화면으로, 손님과 같이 고를 때 씁니다. 담으면 오른쪽 주문서에 그대로 들어갑니다. 주문서에서 바코드를 누르면 그 상품의 사진·구성·행사가 새 창으로 뜹니다. 인쇄물은 어느 쪽에서 뽑아도 똑같습니다.
로그인 확인 1·2·3번은 GitHub 로그인 상태여야 합니다. 로그아웃 상태로 열면 “Uploads are disabled” 처럼 버튼이 아예 보이지 않습니다. 로그인하고 새로고침하면 나옵니다.

클로드 코드에 맡기는 방법 (준비 ~ 3단계)

직접 하지 않고 대신 시킬 수도 있습니다. 건네줄 것은 두 가지뿐입니다.

  1. 새 시즌 카탈로그 사이트 주소
    예: https://gs25mobile.com/2027_1st/category — 주소창에 보이는 그대로. /products.json 은 알아서 붙입니다
  2. 바코드북 PDF — 파일이나 내려받을 링크

이렇게 말씀하시면 됩니다.

새 시즌 갱신해줘
카탈로그: https://gs25mobile.com/2027_1st/category
바코드 PDF: (파일 또는 링크)

그러면 이렇게 진행됩니다.

  • 카탈로그가 열리는지, 상품 수, PDF와 상품코드가 1:1인지 먼저 확인합니다
  • 사전행사 배너 그림을 읽어 행사 날짜 3가지를 뽑고, 맞는지 먼저 여쭙습니다
  • 처음 보는 구매혜택 아이콘이 있으면 그림과 함께 보여드리고 확인받습니다 (2+1 과 3+1 은 글자 하나 차이라 단정하지 않습니다)
  • 시즌설정.txt 를 고쳐 올려두고, 3단계 실행 버튼은 사장님이 누르시는 쪽을 권합니다 — 1년에 한 번 관리자 경로가 살아 있는지 확인되고, 실행 기록에 검산할 숫자가 남습니다
★ 이것만은 대신 못 합니다 바코드 스캔 확인입니다. 카탈로그에 바코드 번호가 아예 없어서 맞춰볼 정답이 없기 때문입니다. 4단계 확인은 그대로 사장님 몫입니다.

00준비 — 두 가지를 적어두세요

실제로 고칠 값은 6개뿐입니다. 그중 4개를 여기서 미리 알아냅니다.

준비 A — 카탈로그 주소 찾기

  1. 새 시즌 GS25 카탈로그 사이트를 엽니다
    https://gs25mobile.com/2026_2nd/category
  2. 주소창에서 /category 앞부분까지가 카탈로그 폴더입니다
    https://gs25mobile.com/2026_2nd
  3. 거기에 /products.json 을 붙입니다
    https://gs25mobile.com/2026_2nd/products.json
✅ 이렇게 되면 성공 그 주소를 브라우저 주소창에 붙여넣고 엽니다. 글자가 빽빽하게 잔뜩 나오면 정상입니다. 무슨 뜻인지 읽으실 필요는 없습니다. “404”나 빈 화면이면 주소가 틀린 것입니다.

시즌 폴더 이름은 매번 바뀝니다. 2026_2nd(추석) 다음은 보통 2027_1st(설날)입니다.

준비 B — 행사 기간 3가지 적기

카탈로그 사이트에서 사전행사(사전예약) 안내 배너를 찾습니다. 이렇게 적혀 있습니다.

사전 구매 증정 행사  2026.08.17(월) ~ 2026.09.04(금), 19일간
삼성/KB국민/비씨/신한카드 결제 시
적을 값위 예시라면어디서 나오나
사전행사 시작2026-08-17배너의 시작일 그대로
본행사 시작2026-09-05배너의 끝난 날 + 1일
사전행사 조건삼성/KB국민/비씨/신한카드 결제 시배너의 조건 문구 그대로
⚠️ 여기서 제일 많이 틀립니다 본행사 시작은 배너에 안 적혀 있습니다. 사전행사가 끝난 다음 날입니다. 위 예시는 사전행사가 9월 4일에 끝나므로 본행사는 9월 5일입니다.

조건 문구가 따로 없으면 사전행사 조건: 뒤를 비워두시면 됩니다. 사전행사 시작 전에는 어떤 행사도 자동 선택되지 않습니다.

✅ 공짜 검산 배너에 “총 ○○품목” 같은 숫자가 있으면 함께 적어두세요. 3단계 실행 결과에 나오는 사전행사 품목 수와 같아야 합니다.

보통 고치는 건 아래 6줄뿐입니다. 위의 매장 3줄은 담당자나 전화번호가 바뀌었을 때만 고치시면 됩니다 (주문서 맨 위에 그대로 표시됩니다). 다 고치면 아래 Commit changes 를 누릅니다.

응답 시트 주소는 주문이 쌓이는 구글 스프레드시트 주소로, 시즌과 상관없이 한 번만 적어두면 됩니다. 관리자 홈에 “주문 내역 시트” 버튼으로 나옵니다. 쓰지 않으시면 쌍점 뒤를 비워 두셔도 됩니다.

주문 확인 화면 — 시트 탭을 안 뒤져도 됩니다 (최초 1회)

주문이 쌓이면 시트 탭이 계속 늘어나 찾기가 어려워집니다. 주문 확인 화면은 들어온 주문을 목록으로 보여주고, 하나 누르면 주문서 모양으로 펼쳐 줍니다 (바코드까지 나오고 인쇄도 됩니다).

응답 시트 → 확장 프로그램 → Apps Script → 배포 → 새 배포 → 유형 ‘웹 앱’

고를 것값
실행 계정웹 앱에 액세스하는 사용자
액세스 권한Google 계정이 있는 모든 사용자

배포하면 주소가 하나 나옵니다. 그 주소를 시즌설정.txt 의 주문 확인 주소 줄에 넣고 갱신을 한 번 돌리면 (바코드 다시만들기는 해제) 관리자 홈에 버튼이 생깁니다.

실행 계정을 ‘나’ 로 두지 마세요 그러면 주소만 알면 누구나 손님 이름·전화번호·주소를 다 보게 됩니다. ‘웹 앱에 액세스하는 사용자’ 로 두면 스크립트가 접속한 사람 자격으로 시트를 읽어서, 시트를 공유받은 사람만 볼 수 있습니다.

다른 분도 보셔야 하면 그분 구글 계정에 이 시트를 보기 권한으로 공유하시면 됩니다. 공유 목록이 곧 이 화면의 출입 명단입니다. (다만 그분은 시트 원본도 열 수 있게 됩니다.)

코드를 고친 뒤에는 배포 관리 → 수정 → 버전: 새 버전으로 다시 배포해야 화면에 반영됩니다. 저장만 해서는 옛 화면이 그대로 뜹니다.

술(주류)은 적을 게 없습니다 — 막힐 때만 봐주세요

주류는 택배로 못 보내서 주문서가 매장 수령 안내를 대신 띄웁니다. 어떤 상품이 술인지는 3단계에서 카탈로그 분류 이름을 보고 알아서 찾습니다 (2026 추석은 양주/와인, 소주/전통주 — 85품목). 평소엔 적을 것이 없습니다.

못 찾으면 3단계가 멈추면서 이번 시즌 분류 이름을 전부 보여 줍니다. 그때만 그 이름을 보고 한 줄 추가하세요. 

배송불가 분류: 양주/와인, 소주/전통주      ← 보여준 이름 그대로
배송불가 분류: 10, 11                     ← 이름이 안 나왔으면 목록의 몇 번째인지 번호로
배송불가 분류: 없음                        ← 술이 아예 없는 시즌
다음 시즌에 반드시 지우세요 분류 번호와 이름은 시즌마다 바뀝니다. 지난 시즌 줄을 그대로 두면 엉뚱한 상품이 배송 불가가 됩니다. 지워두면 다시 알아서 찾습니다.

04확인 — 생략하지 마세요

갱신이 초록 체크로 끝나도 반드시 확인해 주세요.

👉 실제 주문서 열기 즐겨찾기 4

확인 1 · 상품 이름과 가격

주문서에서 상품코드 5개쯤 넣어보고 카탈로그와 대조합니다. 첫 코드, 중간 코드, 마지막 코드를 섞어서 골라주세요.

이름은 자동 상품 이름은 갱신할 때 바코드 PDF와 카탈로그를 601개 전부 맞춰보고, 하나라도 다르면 갱신이 멈춥니다. 그러니 여기서는 가격과 “화면에 새 시즌이 반영됐는지”를 위주로 보시면 됩니다. 가격은 카탈로그에만 있는 값이라 대조할 상대가 없어, 눈으로 보는 것이 유일한 확인입니다.

확인 2 · 행사

카탈로그에 적힌 행사와 같은지 봅니다. 지금이 사전행사 기간이면 본행사 상품은 행사가 안 붙는 게 정상입니다. (아래 행사 미리보기 참고)

확인 3 · 바코드 스캔

★ 제일 중요합니다

인쇄해서 실제 스캐너로 찍어보세요.

명절마다 같은 상품코드가 다른 상품을 가리킵니다. 2026 추석에는 그대로 남은 코드 371개의 내용물이 바뀌었습니다. 여기가 틀어지면 주문서에 찍힌 바코드가 엉뚱한 상품으로 스캔됩니다.

화면상으로는 아무 문제가 없어 보이기 때문에, 스캔해보지 않으면 모릅니다.

행사 미리보기

상품마다 사전행사와 본행사 행사가 다릅니다. 2026 추석 기준으로 601개 중 289개가 서로 다르고, 167개는 본행사에야 행사가 켜집니다.

예시 08-05 농협안심 한우 1호 → 사전행사 없음, 본행사 5+1. 지금 행사가 안 붙는다고 잘못된 게 아니라, 본행사 시작일부터 붙습니다.

본행사가 시작되기 전에 “그날 화면이 어떻게 보이는지” 미리 볼 수 있습니다.

테스트 모드 끄기

⚠️ 빨간 띠가 보이면 테스트 중입니다 테스트 중에는 화면 맨 위에 빨간 띠가 뜨고 인쇄물에도 찍힙니다. 테스트로 뽑은 주문서가 진짜와 구분되지 않으면 안 되기 때문입니다. 빨간 띠가 보이는 주문서는 실제 주문에 쓰지 마세요.

끄는 방법 세 가지 — 빨간 띠의 테스트 끄기 버튼 / 관리자 메뉴의 테스트 끝내기 / 그냥 탭(창) 닫기.

주의 주소에서 ?admin=1 만 지우는 것으로는 꺼지지 않습니다. 관리자 메뉴만 사라지고 테스트 모드는 그 탭에 남습니다. 그때는 빨간 띠의 테스트 끄기 를 누르세요.

바뀌는 것은 행사 자동 선택에 쓰는 날짜뿐입니다. 주문 일시와 배송 희망일은 실제 날짜 그대로입니다.

판단 기준 빨간 띠가 없으면 진짜 주문서입니다.

실행이 빨간 ✗ 로 끝났을 때

먼저 안심하세요 실패해도 주문서는 그대로입니다. 갱신이 끝까지 성공했을 때만 반영되기 때문입니다.

빨간 ✗ 를 누르고 시즌 갱신 실행 항목을 펼치면 [!] 로 시작하는 줄에 원인이 있습니다.

“확인이 필요한 아이콘” 이 나오면

행사 표시(1+1, 2+1 …)는 카탈로그에 숫자가 아니라 그림으로만 들어 있습니다. 그래서 프로그램이 아이콘 그림 자체를 기억해 두었다가 새 시즌 그림과 맞춰봅니다.

  • 그림이 지난 시즌과 똑같으면 — 번호가 12번에서 37번으로 바뀌었어도 알아서 같은 행사로 처리합니다. 하실 일이 없습니다.
  • 그림이 처음 보는 것이거나 번호는 그대로인데 그림이 바뀌었으면 — 이때만 멈추고 물어봅니다. 이 부분만 사람 손이 필요합니다.

물어보면 이렇게 하세요.

  1. 실행 화면 맨 아래 Artifacts 에서 확인이-필요한-아이콘 을 내려받습니다
    (번호가 붙은 그림 한 장에 모아 놓았습니다)
  2. 그림을 보고, 실행 기록이 알려준 줄을 시즌설정.txt 맨 아래에 붙여넣고 값만 고칩니다
구매혜택 56: 3+1      ← 그림에 "3+1" 이라고 적혀 있으면
구매혜택 57: 없음      ← 무료배송·냉장·할인 등 덤이 아닌 그림이면 '없음'
👉 설정 편집 화면 열기 즐겨찾기 2
  1. 저장하고 3단계를 다시 실행합니다
한 번만 하면 됩니다 한 번 적어두면 그 그림은 계속 기억되므로, 다음 시즌부터는 다시 묻지 않습니다.

그림에 9월 5일부터 같은 날짜가 함께 적힌 것도 있습니다. 비율만 보고 적으면 됩니다 (3+1 9월 5일부터 → 3+1).

제일 조심할 경우 “번호는 그대로인데 그림이 바뀌었습니다” — 그냥 넘어가면 작년 비율로 올해 주문이 나갑니다. 일부러 멈추게 해두었습니다.

자주 묻는 것

잘못 눌렀는데 되돌릴 수 있나요?

네. 모든 갱신이 기록으로 남습니다. 개발자에게 “이전 상태로 되돌려달라”고 하면 됩니다. 불안하시면 확인만하기 옵션으로 먼저 돌려보세요.

매장 전화번호만 바꾸고 싶어요

시즌설정.txt 의 해당 줄만 고치고, 바코드도 다시만들기 체크를 해제하고 실행하세요. 몇 초면 끝납니다.

season.json 은 뭔가요? 고쳐야 하나요?

아니요. 구매혜택 아이콘 그림을 기억해두는 파일이라 프로그램이 알아서 씁니다. 갱신할 때마다 자동으로 바뀌므로 열어보거나 고치지 마세요.

행사가 카탈로그와 다르게 나옵니다

주문서의 행사 칸은 언제든 직접 바꿀 수 있습니다. 매장 사정으로 다른 경우가 있어, 자동 선택은 어디까지나 처음 채워주는 값입니다.

화면이 예전 그대로예요

브라우저가 옛 파일을 기억하고 있는 것입니다. Ctrl+F5 로 강제 새로고침하세요.

술을 넣으니 배송 정보 칸이 사라졌어요

정상입니다. 주류는 택배로 보낼 수 없어 매장에서 직접 수령해야 합니다. 주문한 상품이 전부 주류면 받을 배송지가 없으므로 배송 정보 칸 대신 빨간 안내가 표시되고, 그 안내는 인쇄물에도 함께 나옵니다. 일반 상품이 하나라도 섞여 있으면 배송 정보 칸은 그대로 있고, 주류만 배송 상품 목록에서 빠집니다.

주류를 몇 개로 보고 있나요?

관리자 홈 지금 상태의 배송 불가 (주류) 칸에 품목 수와 분류 이름이 나옵니다 (2026 추석은 85개 · 양주/와인, 소주/전통주). 여기에 판별 불가라고 떠 있으면 분류 이름을 못 읽은 것이라 주문서가 주류를 가려내지 못합니다 — 갱신을 다시 돌려 주세요.

수량과 지급수량이 왜 다른가요?

수량은 손님이 돈 내는 개수, 지급수량은 실제로 나가는 개수(덤 포함)입니다. 2+1 행사에서 10개를 사면 수량 10 / 지급수량 15 이고, 금액은 10개 값입니다. 행사는 값을 깎는 게 아니라 덤을 더 주는 방식입니다.
